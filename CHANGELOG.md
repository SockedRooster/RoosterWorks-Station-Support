# Changelog

## 0.3.0-alpha3 — Panel-clad truss and Hex adapter

- Added **Hex → round 1.25 m** size1 stack adapter, compatible with the Hex girders.
- Preserved existing Octo → round 2.5 m size2 adapter.
- Extended the internal monopropellant vessels nearly from top to bottom structural rings.
- Rotated the battery housings flat against the inner polygon faces, with visible mounting rails and cables.
- Expanded armored exterior to continuous end-to-end panel-clad truss coverage, with manufactured panel seams and exposed primary beams.
- Corrected label UV mapping in both axes to address mirrored/upside-down lettering reported in KSP.
- No storage, mass, part IDs, or stock variant types changed for the existing four girders.
- Six playable-test models; structural verification only pending VAB and Kerbalism tests.

## 0.2.0-alpha2 — Original revised girder prototype

- Four support girders with Open Frame / Armored Panels visual variants.
- Added Octo-to-2.5m adapter.
