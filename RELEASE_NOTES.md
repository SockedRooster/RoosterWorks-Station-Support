# RoosterWorks Station Support v1.0.0

Six new, original station-support parts for KSP 1.12.5 by SockedRooster.

**Includes:** Octo XL, Octo Medium, Hex Long, Hex Medium, Octo → 2.5 m adapter and Hex → 1.25 m adapter.

- Fixed support-only ElectricCharge and MonoPropellant storage, with four capacity options (9,000/1,500; 4,500/750; 1,200/200; 600/100).
- Open Frame / Armored Panels stock VAB variants on all four girders.
- Original high-detail static geometry, outward-facing battery modules, RoosterWorks badges and mini green indicators.
- Collision approximations, fixed stack connections and early-to-mid career unlocks.
- No required external mod. Kerbalism and VAB Organizer are optional.

**Install:** Download and extract `RoosterWorks-Station-Support-v1.0.0.zip` into your KSP game root. Delete the previous `GameData/RoosterWorksStationSupport` folder first; also remove the old `RoosterWorksKerbalismAdditions` prototype folder if installed.

**Important limitations:** Battery LEDs are static; KSP textures are simplified. Creator-approved appearance is confirmed in the VAB, but extensive flight, docking/attachment stress and Kerbalism background-persistence tests have not been documented.
