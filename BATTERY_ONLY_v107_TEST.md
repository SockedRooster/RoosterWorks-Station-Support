# v1.0.7 Selectable battery storage TEST

Six existing support girders now have a **Storage** dropdown using B9 Part Switch, independent of the existing stock Open Frame / Armored Panels / Armored Grey appearance selector.

- Hex Medium: 2,000 EC battery-only
- Hex Long: 4,000 EC battery-only
- Octo Medium: 15,000 EC battery-only
- Octo XL: 30,000 EC battery-only
- Octo 3.75 Medium: 33,000 EC battery-only
- Octo 3.75 XL: 66,000 EC battery-only

Default remains the original EC + MonoPropellant capacity for existing craft.
No duplicate parts are created. B9PartSwitch is a NEW REQUIRED DEPENDENCY for these six part configs. Do not install this test package without B9PartSwitch.
No gameplay test has been performed; confirm switch behavior, resources, and craft persistence in KSP before release.
