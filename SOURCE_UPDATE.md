# Source update

GameData contains the accepted test.9 runtime promoted to v1.0.10. The version descriptor and installation notes are the only changed runtime files. Tools/Development contains the incremental authoring scripts from the development workspace. Those historical scripts reference intermediate builds. Run python Tools/package_release.py from the extracted source to package the committed runtime directly.

Historical preview renders are listed in Docs/ARCHIVED_PREVIEWS.txt. To run older visual-review checks, extract those paths from RoosterWorks-Station-Support-v1.0.9-GitHub-Source.zip into this source folder. They are optional for packaging the current release.
